# Old-Analysis — pre-fix era archive

This directory holds everything from the GRBV Transcriptomics project
that predates the fix pass (2026-04-20 onward). It is kept for
reproducibility and reviewer-trail reasons; **the current analysis
pipeline does not read from here**.

Archive created on 2026-04-22 as part of the folder-streamlining
cleanup. See the parent CLAUDE.md for what the fix pass changed and why.

## Contents

### `images/`  (55 PNGs, ~60 MB)

All pre-fix figure renders generated by the original Python pipeline
(`Old_figure/png/` + 8 root-level PNGs that were kept at the repo root
because the atlas builder classified them as "current").

- 47 numbered figures from the original `01_*` through `55_*` series
  (produced by `analysis.py`, `pathway_enrichment.py`,
  `causal_mediation_analysis.py`, and siblings in `scripts_python/`).
- 8 PNGs previously kept at repo root

The post-fix equivalents are in `../figures/main/` (Main01–Main10) and

`../farm_pipeline/results/fix01_de_redo/` and `fix01c_de_extras/`.

## Why these are kept at root (not archived)

Several CSV files at the repo root look pre-fix by name or timestamp
but are **actively read by the current R figure scripts**:

- `heat_stress_DEGs_all_conditions.csv`, `heat_DEGs_recurrence.csv`
  (Main04, S34, S35)
- `gsea_results_all_conditions.csv` (Main09, S37–S39)
- `chromosome_deg_density.csv` (Main08, S51–S52)
- `multifactor_anova_results.csv`, `interaction_gene_categories.csv`
  (S40–S42)
- `tf_family_DE_summary.csv`, `tf_family_gene_details.csv` (Main07, S43–S45)
- `mediation_results.csv` (Main05, S49, S50) — post-fix, fix03 tv=2,000 rerun
- `stability_selection_FIX04.csv`, `advanced_ml_comparison_FIX04.csv` (Main06, S47)
- `MEs.csv`, `hub_genes_per_module.csv`, `module_trait_correlations.csv`,
  `coexpression_modules.csv` (Main07, S53–S55)
- `GRBV_biomarker_QTL_crossref.csv`, `GRBV_biomarkers_top50.csv`,
  `consensus_biomarker_panel.csv` (Main06, Main08)
- `daily_2021.csv`, `daily_2022.csv` (weather inputs for the environment panel)

These are the CSVs with one or more `grep -l "$csv" figures/scripts_R/*.R`
hits at the time of the cleanup. Do not archive them without a matching
script update.

## Restoring a pre-fix artefact

Each file here is the same content that used to sit at repo root (for
the PNGs, PDFs, CSVs, and PPTX) or inside `Old_figure/` (for the
earlier images + scripts sub-archive). If you need to resurrect
one, copy or symlink it back; do not move from here, because the R
pipeline has no dependency on this directory but third-party readers
(e.g., the old Welch-t DOIs) may still.
